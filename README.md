## Scope & Intent: A Living Container
This repository serves as an active, evolving container for my ongoing notestaking, working thoughts, and reference logs—separate from a finalized or formally published series. 

Because this is a living workspace:
* Entries may be experimental, fragmentary, or revised across snapshots.
* Organization reflects how these notes are actively used rather than a static table of contents.
* Zenodo archives periodic checkpoints of this repository under a single overarching **Concept DOI**, ensuring the history of thought remains traceable while always resolving to the latest state of the container.

## Archival & Snapshot Logic
A GitHub Release is triggered periodically to push a state snapshot to Zenodo. These releases represent chronological checkpoints and backup states rather than formal "editions" or standalone volumes.

* **To reference the living container as a whole:** Cite the overarching **Concept DOI** at the top of this README.
* **To reference a specific note as it existed on a given date:** Cite the specific **Version DOI** corresponding to that snapshot on Zenodo.
